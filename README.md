# ofxSonyDeckControl

openFrameworks class for controlling Sony broadcast decks over the 9-pin RS-422 (Sony P2) protocol through a serial adapter. Covers transport control and status flags (playing, recording, jog, cassette, near end of tape). `src/ofApp` is a small test app.

## Build

- No extra addons. Generate the project with projectGenerator.
- Needs a USB to RS-422 adapter; set the serial port in `ofApp`.

Work in progress from 2014, kept for reference.
